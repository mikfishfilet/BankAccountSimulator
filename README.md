#BankAccountSimulator

#Description
This simulator is designed to make deposits and withdrawawls and show the ending balances of accounts.

# How to Run
1. Open the project in a Java IDE such as IntelliJ IDEA.
2. Make sure `BankAccount.java` and `Main.java` are in the project.
3. Run `Main.java`.
4. The program will display the starting account information, perform several transactions, demonstrate invalid transactions, and display the final account information.
